# Contributing to dotbot-install

When changing this repository, load `development-principles-instructions`, then follow `development-principles-wiki`.
The wiki lives at `wiki/` relative to this Git root, including when the plugin is checked out as a submodule.
Its development-memory identity is `https://github.com/budmonde/dotbot-install.git`.

- Read the [mission](wiki/mission.md) to decide whether a proposed behavior belongs to the plugin, Dotbot, or an installer.
- Follow the [contribution workflow](wiki/workflow.md) when changing the runner, directive, or contract published to consumers.
